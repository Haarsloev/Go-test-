# DNDGO v1.4 – korrigeret filstruktur

`index.html` er startfilen til GitHub Pages. `css/style.css` indeholder styling og `js/main.js` indeholder spillets JavaScript.

Upload hele indholdet af denne ZIP til roden af dit repository. Behold mapperne `css` og `js`.

`play.html` er den selvstændige alt-i-en version til lokal test.

Bemærk: Dette er en **filstruktur-rettelse** af v1.4, ikke en ny gennemtestet gameplay-version.
